# 🏎️ ASTRA CHASE

A cinematic 3D browser driving game — a high-speed escape through a hostile futuristic transport network.

## ▶️ Play it live

**[Play ASTRA CHASE](https://arecibo-sys.github.io/astra-chase/)**

## About

ASTRA CHASE is a next-generation evolution of the OX ALPHA car chase experience. You drive a powerful futuristic vehicle through enormous urban and industrial environments while autonomous pursuit machines chase, flank and ram you. Civilian traffic keeps moving around the pursuit, creating unpredictable close passes, collisions and narrow escapes.

The chase is the game. Crashes and impacts cost momentum — they never end the run.

## Features

- **8 continuous sectors** — daylight corridor, industrial perimeter, sublevel tunnels, rain district, central grid, night transit, system collapse, and the final ASTRA climb. No loading screens between them.
- **Cinematic third-person chase camera** — FOV widens with speed, inertia and camera modes (T to cycle).
- **Weighty vehicle physics** — visible suspension, wheel rotation, body lean, brake nose-dip.
- **Intelligent pursuit AI** — interceptors, flankers, ram units and scouts with positional intent and escalating pursuit heat.
- **Varied civilian traffic** — multiple vehicle types, lane changes, ramp entries, density rhythm.
- **Collisions that cost momentum, never end the run** — sparks, debris, camera shock, recoverable.
- **Restrained engineered aesthetic** — graphite, warm/cold white, dark metal, black glass, deep atmospheric fog, procedural sky.
- **Layered Web Audio** — engine, wind, impacts, pursuit tones, tunnel reverb, plus a dark minimal evolving electronic score (sound off by default).
- **Full controls** — desktop (WASD/arrows, T camera, M mute, Esc pause) + native iPhone/iPad touch layout with multitouch.
- **Adaptive quality** — HIGH / MEDIUM / MOBILE auto-detected.

## Tech

- Single-file HTML + CSS + JavaScript
- Three.js (WebGL) from CDN
- No backend, no account, no ads, no analytics
- GitHub Pages–deployable

## Controls

- **W / ↑** — accelerate
- **S / ↓** — brake
- **A / D / ← / →** — steer
- **T** — cycle camera
- **M** — toggle sound
- **Esc** — pause
